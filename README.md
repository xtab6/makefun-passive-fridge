Notes From a Passive-Aggressive Fridge — one line a smart fridge leaves for its owner. `main.py` writes it to `/output/entry.txt`:

> My log shows 47 'I'll eat it tomorrow' promises about the same container. Tomorrow just filed for a restraining order.

The fridge keeps a log of every broken "I'll eat it tomorrow" promise about the same container — and the turn is that Tomorrow itself has filed for a restraining order. 118 characters, one line, dry, petty and specific.

## Run it

```sh
python3 main.py
```
